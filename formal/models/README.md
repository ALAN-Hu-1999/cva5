# Formal models

- `full_core/`: CVA5 wrappers, FBM, and fetch-local harness.
- `unit_axi_master/`: read, write, combined, and Jasper proof-framework tops.
- `legacy/`: legacy AXI master and checker harnesses.

The full-core top is `full_core/cva5_axi_proof_framework_wrapper.sv`; unit
harnesses are separate proof tops.
